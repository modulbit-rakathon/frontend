# Pillgaze Frontend

Frontend repozitář projektu **Pillgaze**.

## O projektu

Tento repozitář slouží pro vývoj klientské (frontend) části projektu Pillgaze.

## Stav repozitáře

Aktuálně je zde připraven základ repozitáře a tato dokumentace.

## Jak začít

1. Naklonuj repozitář:
   ```bash
   git clone <url-repozitare>
   cd frontend
   ```
2. Doplň nebo inicializuj frontendovou aplikaci podle zvoleného stacku (např. React/Vue/Next.js).
3. Přidej skripty pro vývoj, build a testy do `package.json`.

## Doporučená struktura (návrh)

```text
frontend/
  src/
  public/
  package.json
  README.md
```

## Poznámka

Jakmile bude aplikace rozpracovaná, doporučuje se README doplnit o:
- přesné požadavky na prostředí,
- instalační kroky,
- příkazy pro spuštění, testy a build,
- stručný popis architektury.
